# Writing Directory Rules

When working in `papers/` and `analysis/`:

## papers/outline.md

- Must exist and be approved BEFORE any section drafting begins
- Changes to the outline after drafting has started require Paper Author sign-off
- The "Central Argument" field must be kept current — this is the north star

## papers/drafts/

- One file per section
- Naming: `abstract.md`, `introduction.md`, `related-work.md`, `method.md`, `experiments.md`, `conclusion.md`
- Status in first line: `<!-- Status: DRAFT / REVIEWED / APPROVED -->`
- Never edit a section after it's APPROVED without changing status back to DRAFT

## Figures and Tables

- Figures MUST be generated by scripts in `analysis/figures/`, not created manually
- Tables MUST be generated by scripts in `analysis/`, not typed by hand
- Every number in a table must be traceable to a result file in `experiments/results/`
- Before final submission: run the table-generation scripts and verify numbers match paper

## Citation Rules

- All citations in BibTeX format in `literature/bibliography.bib`
- Entry format: `@article{AuthorYearKeyword, ...}` — e.g., `@article{Vaswani2017Attention, ...}`
- Required fields: author, title, booktitle/journal, year
- No citation from memory — always verify the venue and year

## Language Standards

Avoid these in paper prose:
- "Interesting" (show, don't tell)
- "Novel" (the novelty is shown by the contribution, not stated)
- "Significantly" (use the actual number)
- "Very", "quite", "rather"
- "In this paper, we..." (as an opening — especially for the conclusion)
- Passive voice when active is clearer: "We show X" not "X is shown"

## Limitations Section

Required by NeurIPS, ICML, ICLR, ACL, and most other top venues since 2022.
Must be honest — it's better to state them yourself than have a reviewer do it.

Minimum content:
1. A condition under which the method would fail or underperform
2. A type of task or data the method is not designed for
3. A resource or data requirement that limits applicability
